# Hacker House Goa 2026 | Frame & Builder Badge Generator

An instant web tool where participants upload a photo and get an official branded **Hacker House Goa 2026 PFP Frame Overlay** or **Builder Badge Pass**, ready to download and share on X (Twitter).

![Hacker House Goa 2026 Theme](https://raw.githubusercontent.com/Kunal628-hue/id-card-generator/main/public/favicon.svg)

---

## 🌴 Key Features

- **Format A (Profile Frame / Overlay)**: Concentric yellow and hot pink ring overlay around your photo, featured with the official Devanagari **"गोवा"** hot pink sticker badge and `#FrameInGoa` hashtag.
- **Format B (Builder ID Badge)**: Event badge layout featuring your photo, full name, role/stack, X handle (`@username`), customizable badge tier, and generated builder title.
- **Client-Side Processing**: 100% client-side HTML5 Canvas rendering at **2000x2000 px** resolution. Zero image uploads to servers.
- **Wide Format Support**: Accepts JPG, PNG, WEBP, and native iPhone **HEIC** photos.
- **Instant Photo Editing**: Real-time zoom, rotation, pan X/Y controls, and direct drag-on-canvas positioning.
- **1-Click X (Twitter) Share**: Pre-filled tweet text with hashtag `#FrameInGoa`, tag `@HHGoa`, and automatic image clipboard copy.

---

## 🛠️ Tech Stack

- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Official HH Goa 2026 Emerald Green, Electric Yellow & Hot Pink theme
- **Typography**: Playfair Display (Serif), Rozha One & Noto Sans Devanagari, Plus Jakarta Sans
- **Image Conversion**: `heic2any` (Client-side iPhone HEIC processing)

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Kunal628-hue/id-card-generator.git

# Navigate to directory
cd id-card-generator

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
